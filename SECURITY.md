# Política de seguridad

Si detectas algún problema de seguridad, vulnerabilidad o uso fraudulento de este sitio:

- No lo publiques de forma abierta.
- Envíanos un reporte detallado al correo: **seguridad@agroconnections.mx**.
- Incluye, en la medida de lo posible, evidencia y pasos para reproducir el problema.

Nos comprometemos a revisar los reportes de buena fe y tomar acciones correctivas.
