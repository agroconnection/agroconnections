# Instalar la app en el celular

La app se instala como PWA. No necesita Play Store ni AppGallery.

## Requisito

Primero debe estar publicada en internet, por ejemplo en Render.

La direccion se vera parecida a:

```text
https://control-financiero-nube.onrender.com
```

Esa direccion funcionara desde datos moviles o cualquier Wi-Fi. La PC no tiene que estar encendida para capturar archivos.

## Seguridad

Aunque la direccion exista en internet, la app es privada:

- Pide correo y contrasena.
- Solo entran los usuarios dados de alta en Supabase.
- Los capturistas solo suben informacion.
- Admin/contador revisan y administran.

## Huawei Browser

1. Abre la direccion publica de la app.
2. Inicia sesion.
3. Entra a `Instalar`.
4. Si aparece el boton `Instalar aplicacion`, tocalo.
5. Si no aparece, abre el menu del navegador.
6. Elige `Agregar a pantalla principal` o `Añadir a pantalla de inicio`.
7. Confirma el nombre `Control Financiero Nube`.

## Chrome o Edge en Android

1. Abre la direccion publica.
2. Inicia sesion.
3. Entra a `Instalar`.
4. Toca `Instalar aplicacion` si aparece.
5. Si no aparece, usa el menu de tres puntos y elige `Instalar app` o `Agregar a pantalla principal`.

## Despues de instalar

- Aparecera un icono en la pantalla de inicio.
- Puedes abrirlo como app.
- Puedes subir tickets, facturas, estados de cuenta, PDF o imagenes desde cualquier lugar.
- Cuando la PC se encienda, sincronizas y haces OCR/revision desde la app de escritorio.

## Si no aparece instalar

- Verifica que estes usando la URL con `https://`.
- Refresca la pagina.
- Entra a `Instalar` dentro de la app.
- Prueba Chrome o Edge si Huawei Browser no muestra la opcion.
